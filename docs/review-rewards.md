# 리뷰 기프티콘 이벤트 운영

리뷰 이벤트는 이메일 인증을 마친 회원의 리뷰만 대상으로 하며, 회원당 캠페인별 응모권은 1개입니다. 기존 익명 리뷰는 회원을 확인할 수 없어 응모 대상에서 제외됩니다.

## 캠페인 준비

1. Django Admin의 `리뷰 경품 > 리뷰 경품 캠페인`에서 캠페인을 생성합니다.
2. 시작·종료 시각과 당첨 인원을 설정하고 상태를 `응모 중`으로 변경합니다.
3. `리뷰 경품 > 기프트 쿠폰`에서 당첨 인원 이상의 쿠폰을 등록합니다.
   - 쿠폰 코드, 교환 링크, 기프티콘 이미지 중 하나 이상이 필요합니다.
   - 이미지는 당첨 이메일에 첨부됩니다.

## 추첨 및 발송

1. 캠페인 종료 시각이 지난 뒤 캠페인 목록에서 대상을 선택합니다.
2. `선택한 캠페인 추첨 및 이메일 발송` 작업을 실행합니다.
3. 시스템이 캠페인 기간 내 리뷰를 다시 집계하고 회원당 1개의 응모권을 확정합니다.
4. 당첨자에게 쿠폰을 할당하고 Celery를 통해 인증 이메일 주소로 발송합니다.
5. 발송 실패 건은 `리뷰 경품 > 캠페인 당첨자`에서 선택해 다시 발송할 수 있습니다.

추첨은 한 캠페인에 한 번만 실행할 수 있습니다. 후보 수, 후보 목록 해시, 추첨 시드와 실행 시각이 캠페인에 기록됩니다.

## 배포 체크리스트

- Django 마이그레이션 실행
- API와 Celery Worker 재배포
- SMTP 환경변수(`EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`, `DEFAULT_FROM_EMAIL`) 확인
- 운영 전 테스트 캠페인과 테스트 쿠폰으로 수신 확인
