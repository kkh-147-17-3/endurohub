# Storybook 변경 전 기준

기준 커밋: `b3fab0b20a66bf895d615ae14174bb1c688c6c3f`

이 디렉터리는 정보 위계와 점 표시를 정리하기 전의 실제 소스를 보관합니다. `git show b3fab0b20a66bf895d615ae14174bb1c688c6c3f:web/src/…`에서 추출했으며, 비교 결과를 재현하기 위해 변경 전의 장식용 점과 반복 텍스트도 그대로 유지합니다. 이후의 UI 규칙을 이 기준본에 소급해서 적용하지 않습니다.

컴포넌트 구현을 재작성하거나 근사하지 않았습니다. 복사된 컴포넌트끼리의 `$lib` import만 `$before/lib`로 연결했으며, 변경되지 않은 날짜·타입·계산·분석 유틸리티는 기존 `$lib`를 사용합니다. 상대 import는 원래 구조를 유지합니다. 추출한 파일 목록과 변환 범위는 `provenance.json`에 기록했습니다.

`lib/styles/eh-components.css.txt`와 `eh-tokens.css.txt`는 변경 전 스타일 원문입니다. Storybook에서 `?raw`로 읽어 변경 전 iframe에만 주입하세요. 전/후를 같은 문서에 렌더링하면 전역 스타일이 섞이므로 각각 독립 iframe으로 비교합니다. `app.css.txt`는 전체 앱 스타일의 참고 원문이며 직접 CSS import하지 않습니다.

달력의 날짜 판단, 탐색과 필터 동작은 현재 실행 환경을 사용하므로 비교 데이터·날짜·필터·뷰포트는 양쪽에 동일하게 제공해야 합니다. API 요청을 발생시키는 버튼은 실제 서비스에 연결하지 말고 Storybook에서 모킹하거나 비활성화한 상태로 검토합니다.
