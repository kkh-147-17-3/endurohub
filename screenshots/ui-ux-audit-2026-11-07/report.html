EnduroHub UI/UX 및 디자인 개선 검토

2026-11-07 · www.endurohub.kr · 비로그인 · 다크 테마 · 기본 PC 창 및 390×844 모바일 뷰포트

브랜드 방향은 일관적이며 대회 발견·비교·상태 신뢰성을 먼저 보강하는 것이 좋습니다.

권장 순서: 취소 상태 정합성 → 모바일 비교 정보·필터 팝오버 → PC 대회명 가독성 → 홈 검색·빠른 필터 → 선택 보존·기본 정렬 → 키보드 접근성. 작은 캘린더 글자와 어두운 마감 대회명은 크기·대비를 보강하세요. 대회 / 검색 / 2026 대회 / 시즌 메뉴는 대회 일정 / 대회 찾기 / 연간 일정 / 내 시즌처럼 용도가 드러나는 명칭을 검토할 수 있습니다.

1. 홈 진입 — 브랜드 양호, 탐색 개선

흑백 스포츠 이미지·초록 강조색·종목별 색상은 일관적입니다. 히어로와 큰 월 제목의 연속으로 실제 캘린더가 아래에 시작합니다. 히어로·월 헤더 높이를 줄이고 대회명 검색, 지역, 접수 중만 보기의 빠른 진입을 배치하세요. 전체 종목이 선택된 상태에서 한 종목만 보려면 다른 4개를 해제해야 합니다. 전체 옵션을 명시하고 종목·뷰를 URL에 보존하세요. 실측에서 월 이동은 종목 선택을 유지했으나 새로고침 시 초기화되었습니다.

2. 날짜별 목록 — 비교 정보와 접근성 개선 필요

PC에서는 같은 날짜와 RUN 표기가 행마다 반복되는 동안 대회명이 잘립니다. 날짜를 헤더로 통합하고 제목에 넓은 폭과 2줄을 허용하세요. 모바일에서는 지역·거리·참가비·종목이 숨겨집니다. 대회명 아래 지역·거리·참가비를 표시하는 카드형 행을 권합니다. 팝업을 연 뒤 Tab을 누르면 배경의 다음 날짜로 초점이 이동하는 것을 직접 확인했습니다. 열 때 초점 이동, 내부 순환, 배경 비활성화, 닫을 때 복귀가 필요합니다.

3. 모바일 리스트 — 가독성과 기본 순서 개선

2026년 11월 7일 점검에서 첫 행은 지난 11월 1일 접수 마감 대회들입니다. 오늘 이후로 이동, 접수 중만 보기, 지난 대회 포함 옵션을 제공하세요. 모바일 캘린더의 점과 숫자는 일정 밀도를 보기에 유용하지만 대회 비교에는 약합니다. 리스트를 기본으로 제공하는 대안은 실제 이용 데이터와 사용성 테스트로 검증할 수 있습니다.

4. 검색과 상태 필터 — 기능 작동, 모바일 배치 개선

다섯 가지 필터가 있고 접수 중 적용 시 URL·선택 칩·모두 지우기에 반영되는 점은 좋습니다. 기본 결과는 지난 접수 마감 대회부터 시작합니다. 홈의 빠른 진입과 연결하고 기본 정렬과 조회 기간을 명확히 안내하세요. 모바일 상태 팝오버가 오른쪽 경계를 넘어 옵션이 잘리고 가로 스크롤이 나타납니다. 화면 안에 맞춘 패널 또는 하단 시트를 권합니다. RUN·DIST·FEE·ENTRY 보조 라벨은 종목·거리·참가비·접수 마감처럼 한국어로 통일할 수 있습니다.

5. 대회 상세 — 상태 불일치 최우선 수정

2026 하남 미사 대회 취소는 본문에도 취소 안내가 있지만 접수 중 배지, D-19, 접수하기 버튼이 함께 노출되고 접수 중 검색 결과에도 포함됩니다. 취소·연기 상태가 날짜 기반 접수 상태보다 우선하도록 하고 접수 CTA를 취소 안내·공식 공지 확인으로 바꾸세요. 외부 접수는 실행하지 않았습니다. 업데이트 날짜와 공식 사이트, 모바일 하단 CTA의 구조는 유용합니다.

검증 범위와 한계

이번 점검에서 직접 캡처한 화면, 실제 필터·월 이동·새로고침·Tab 키 동작, 로컬 코드의 보조 검토를 근거로 작성했습니다. 전체 접근성 인증 결과는 아닙니다. 로그인 이후 저장, 실제 접수 완료, 스크린리더, 모든 브라우저·기기, 정량 대비 측정, 로딩 성능은 검증하지 않았습니다. 제안의 전환율 효과는 아직 측정하지 않았습니다. 구현 파일은 변경하지 않았습니다.
